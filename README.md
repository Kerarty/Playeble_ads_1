# Color Sort — Playable Ad

Учебный проект: плейбл-реклама (playable ad) в виде одной HTML5-игры.
Механика — **Water Sort / Color Sort**: переливай шары по пробиркам, пока
в каждой не соберётся один цвет. Изюминка — **шар-джокер** (радужный):
подходит к любому цвету и окрашивается в цвет, на который его лили.

Вся игра — один самодостаточный файл `index.html` (~35 КБ): без картинок,
шрифтов и внешних запросов. Это главный формат для рекламных сетей
(Meta, Google Ads, AppLovin, Unity Ads): zip с одним `index.html` внутри,
обычно лимит 2–5 МБ — мы влезаем с запасом в ~100 раз.

## Запуск

Просто открыть `index.html` в браузере, либо:

```bash
python -m http.server 8091
# открыть http://localhost:8091
```

## Тесты уровня

Чистая игровая логика вынесена в блок между `// LOGIC-BEGIN` и `// LOGIC-END`
в `index.html`, поэтому тестируется без браузера:

```bash
node tools/test-level.mjs
```

Тест печатает уровень и решение (BFS), проверяет, что оно приводит к победе.

## Отладка в браузере

Открыть `index.html?debug` — игра пишет состояние в заголовок вкладки
(`DBG <state> <пробирки> dead=<таймер>`), ошибки JS идут туда же с префиксом
`ERR`. Удобно для автотестов через Playwright.

## Как устроен уровень

Уровень детерминированный (сид `SEED`): все игроки получают одну и ту же
раскладку — так проще QA и A/B-тесты креатива. Генератор случайно раскладывает
шары, а затем проверяет раскладку поиском в ширину: бракуются раскладки, где
что-то уже собрано или решение короче 6 ходов. Победа даёт end card с CTA.
Тупик (нет ходов или позиция несобираема) мягко перезапускает уровень —
игрок в плейбл-аде не должен застревать.

## Сборка zip для рекламной сети

```powershell
powershell -Command "Compress-Archive -Path index.html -DestinationPath dist/color-sort-playable.zip -Force"
```

Внутри zip должен лежать именно `index.html` в корне — большинство сетей
требуют именно такое имя.

## Что настроить под кампанию

- `CONFIG.storeUrl` — ссылка на стор. Если в сети есть MRAID, кнопка CTA
  вызовет `mraid.open(url)` автоматически, иначе обычный `window.open`.
- `CONFIG.texts` — все надписи (сейчас на английском, как принято в плейбл-адах).
- `PALETTE`, `SEED` — цвета и уровень.
- Звук синтезируется через WebAudio (никаких файлов), включается после
  первого тапа — как требуют политики автоплея.

## Структура

```
index.html            — вся игра (логика + рендер + звук)
tools/test-level.mjs  — тест генератора и солвера на Node
```
